# Support

For usage questions, open a GitHub Discussion with:

- Long Mission version;
- operating system and Python version;
- mission profile;
- the relevant `MISSION.md` and redacted `state.json` sections;
- the exact command and observed output.

For reproducible bugs, use the bug report template instead of a general discussion.

Do not post secrets, private prompts, private URLs, API keys, or unredacted logs.
