# Progress Ledger
# 进度账本

Append-only entries. Each entry must state: iteration, action, evidence, result, unresolved items, and next action.
只允许追加记录。每条记录必须说明：迭代次数、行动、证据、结果、未解决项和下一步。

```text
## Iteration N — YYYY-MM-DD HH:MM
- Action:
- 行动：
- Evidence:
- 证据：
- Result:
- 结果：
- Unresolved:
- 未解决：
- Next action:
- 下一步：
```
